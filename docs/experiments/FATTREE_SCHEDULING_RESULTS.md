## 0. 结论摘要

研究问题：**网络争用如何改变调度算法的相对优劣？**（3 模型 = V1 无争用 /
R2 端点争用 / R6 Fat-tree 链路争用；4 规划器 = LOCAL_HEFT / LOCAL_CPOP /
PSO / RANDOM；10 个 Pegasus DAX；3 主机同质平台（结构块 4 主机）；seed 91；
静态映射轨道；无显式成本矩阵——成本由 DAX runtime × VM MIPS 推导）

1. **链路束缚恢复，R6 > R2 真实成立**：再标定后链路 0.125 MB/s < 端点 1
   MB/s，fat-tree 链路层成为真实瓶颈。论文例 makespan：HEFT 5195.1 →
   5738.1（+543.0 s，+10.5%）、CPOP 5205.1 → 5854.1（+12.5%）、RANDOM
   6281.1 → 7206.1（+14.7%）、PSO 6254.1 → 7262.1（+16.1%）。模型轴 R6
   vs R2 配对 Wilcoxon：HEFT 中位差 +103.5 s（p=0.0059）、CPOP +104.0 s
   （p=0.0078）、RANDOM +441.8 s（p=0.0039）均显著；PSO +34.5 s
   （p=0.1289）不显著——**链路级争用有规划器选择性**：对 RANDOM 的相对
   惩罚约为 HEFT 的 4 倍（中位差 441.8 vs 103.5 s），对 PSO 相对温和。
2. **决定性交叉验证（F1 修复语义的实测证明）**：再标定 R6 列与 F1 修复前
   R7 黄金值逐位相等（论文例 5738.1/5854.1/7206.1/7262.1；4 主机结构块
   5718.1/5574.1/5186.1/5168.1；弱单调违例 5 处 max 7.47×10⁻⁵）。这同时
   证明两件事：再标定精确恢复了修复前物理区间；F1 单位修复正确（诚实声明
   0.125 与修复前声明 1.0 的实际物理完全一致）。
3. **平均排名不翻转**：三个模型下平均排名均为
   HEFT < CPOP < PSO < RANDOM。列表规划器的平均优势没有被争用推翻。
4. **争用在逐 DAG 粒度翻转第一名（3/10，30%）**：cybershake-n50 第一名
   HEFT(V1) → PSO(R2/R6)；cybershake-n100 第一名 CPOP(V1) → PSO(R2/R6)；
   inspiral-n50 第一名 HEFT(V1) → CPOP(R2) → **HEFT(R6)**。inspiral-n50
   出现 **R2/R6 第一名分化**（再标定后新现象）：R2 下 CPOP 3977749.7549
   以 0.066 s 险胜 HEFT 3977749.8205，R6 下 HEFT 3977781.6601 反以
   0.996 s 反超 CPOP 3977782.6563——噪声级差距在链路争用引入的并发流
   格局漂移下翻转，是链路层在 R2 之上产生独立贡献的直接证据。
5. **带宽比轴 A4 恢复判别力并精确收敛回 R2**：3 主机敏感性 A4（链路 1.25
   MB/s > 端点 ⇒ 非束缚）与主矩阵 R2 **逐位相等**（HEFT 5195.1、CPOP
   5205.1；配对 HEFT 10/10 有效 p=0.0059 中位差 −103.5 s、CPOP 9/10
   有效 p=0.0078 中位差 −104.0 s）。4 主机结构块 A4 严格降低 makespan：
   8/10 DAG 有效（HEFT p=0.0078 中位差 −285.8 s、CPOP p=0.0156 中位差
   −224.2 s）。A4 恢复"链路远宽于端点时收敛回端点主导"的设计语义；修复前
   "10 MB/s" 标签被 ÷8 失真为实际 1.25 MB/s——恰与再标定后的诚实声明值
   相同（结构块数字因此逐位恢复）。
6. **结构轴仍全 DAG 退化（物理现象，非带宽参数问题）**：A1（超收敛 2×）/
   A2（k=8）/A3（k=8 超收敛 2×）/A5（同 edge 热点放置）在 3 主机与 4 主机
   两个平台上与基线**逐位恒等**（配对差值 10(0)，状态
   `UNAVAILABLE_ALL_PAIRED_DIFFERENCES_ARE_ZERO`）。机制：3 主机下任意
   两条并发流必共享一个端点主机；4 主机下交叉流（0→2 与 1→3）实测从未
   并发经过差异链路——路由变体改变共享链路集合但不改变每条链路上的流重叠
   集合，公平份额速率画像不变。路由层契约由 `FatTreeTopologyTest` 锁定
   （A1 下交叉流确实共享 core 链路、A2 单 Pod 化、A5 缩短同 edge 路径）——
   拓扑参数确实重塑路由，恒等是动态层的真实现象。
7. **翻转依赖成本结构**：simulator 探测 IT（论文成本矩阵 fixture）中争用
   把平均第一名从 HEFT 翻转为 CPOP；campaign 配置（推导成本）下平均第一名
   保持 HEFT。两个装置都是实测事实——翻转不是无条件的。
8. **弱单调性 5 处噪声级违例**（V1 ≤ R2 ≤ R6，120 组合）：epigenomics-n100
   PSO R6 < R2（7.47×10⁻⁵）、cybershake-n30 RANDOM V1 > R2（3.7×10⁻⁶）、
   cybershake-n50 HEFT/CPOP/PSO R6 < R2（5.54×10⁻⁶/5.54×10⁻⁶/4.11×10⁻⁶）。
   与 F1 修复前旧物理逐位一致——完成时刻分化后并发流格局漂移所致，非模型
   缺陷；论文例子集严格成立（golden IT 断言）。
9. **历史演化（三段，引用时按此对账）**：
   - **R7 原始**（2026-09-16 上午）：÷8 单位 bug 生效的旧物理（声明 1.0
     实际 0.125），其 R6 列数字与再标定版逐位相等，但声明值失真、R2/V1 列
     为 F2 修复前值；
   - **R8 审计重录**（2026-09-16 上午，诚实单位 + 对称供给 1.0 == 1.0）：

### 3.3 为什么结构轴恒等（证据链）

1. **路由层确实重塑共享格局**（`FatTreeTopologyTest` 结构轴契约）：A1 下
   交叉流共享 core 链路、A2 下单 Pod 化、A5 缩短同 edge 路径——拓扑参数
   不是"没有生效"。
2. **3 主机**：任意两条并发流必共享一个端点主机；改变共享链路集合不改变
   每条链路上的流重叠集合，公平份额速率画像不变 → 恒等。
3. **4 主机**：交叉流（0→2 与 1→3）存在，但在本 campaign 的 DAG × 放置
   组合下从未并发经过差异链路 → 恒等。
4. **A4 对照组**：同一动态层在链路非束缚时行为改变（精确收敛回 R2），证明
   恒等不是引擎失活，而是该负载下结构变体从未让链路份额成为新的最小约束。
5. 恒等作为退化边界如实保留在工件与配对统计中
   （`UNAVAILABLE_ALL_PAIRED_DIFFERENCES_ARE_ZERO`）。激活结构轴判别力需要
   更大平台或更高传输占比的负载（诚实边界 §6）。

## 6. 诚实边界

- **本文结论条件于再标定装置**（链路 0.125 MB/s < 端点 1 MB/s，链路束缚
  生效）。对称供给（链路 ≥ 端点）下 R6 ≡ R2 的全退化仍是边界物理事实
  （`docs/advanced/COMPREHENSIVE_AUDIT_R8.md` §3.3 N-2；simulator 对称探针
  284.1 == R2 锁定），但它不是本装置的现状。
- 排名翻转结论限于本装置：静态映射轨道、3 主机（结构块 4 主机）同质平台、
  seed 91、推导成本（无显式成本矩阵）、10 个 DAX（3 家族；montage/sipht
  被 LOCAL 通信规划族拒绝）。探测 fixture（论文成本矩阵）显示平均排名翻转
  对成本结构敏感（§0.7）。
- inspiral-n50 的 R2/R6 第一名分化幅度为噪声级（R2 差距 0.066 s、R6 差距
  0.996 s，相对 ~10⁻⁸）：分化本身是实测事实，但机制解释（链路争用引入的
  并发流格局漂移放大噪声级差距）是假设，未验证。
- PSO 换冠幅度 0.05%–0.07%，属"数值一致但微小"的翻转；其机制解释（传输
  热点摊开）是假设，未验证。
- 结构轴"恒等"限于本 campaign 的 DAG 集/平台规模/放置/seed；路由层确实
  重塑共享格局（契约测试锁定），更大平台或更高传输占比负载可能激活结构轴。
- R6 模型边界沿用其设计文档：流级流体模型、确定性路由、均匀链路带宽、
  单向链路键（双向流不互扰）。
- RANDOM/PSO 结论条件于 seed 91；跨 seed 稳健性未测。
- 三段演化（§0.9）：R7 原始工件与 R8 审计重录工件均保留在 git 历史；引用
  旧数字时注意 R6 列在再标定下逐位恢复、R2/V1 列因 F2 有微漂移。
