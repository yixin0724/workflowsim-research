## 0. 结论摘要

研究问题：**网络争用如何改变调度算法的相对优劣？**（3 模型 = V1 无争用 /
R2 端点争用 / R6 Fat-tree 链路争用；4 规划器 = LOCAL_HEFT / LOCAL_CPOP /
PSO / RANDOM；10 个 Pegasus DAX；3 主机同质平台；seed 91；静态映射轨道；
无显式成本矩阵——成本由 DAX runtime × VM MIPS 推导）

1. **R6 ≡ R2（本轮最重要的实测事实）**：campaign 声明链路带宽 1.0 MB/s
   与 VM 端点带宽 1.0 MB/s 相等。单位修复后链路容量按声明值真实生效——
   链路容量 ≥ 端点公平份额时链路永不束缚任何单流，fat-tree 链路层对
   makespan 的贡献精确为零：10 DAG × 4 规划器全部 R6 与 R2 **逐位相等**
   （配对差值 10(0) 全零，状态 `UNAVAILABLE_ALL_PAIRED_DIFFERENCES_ARE_ZERO`）。
   这不是模型失效：simulator 慢链路探针（`FatTreeContentionIntegrationTest`，
   链路 0.25 MB/s < 端点 1 MB/s）实测 makespan 588.1 > R2 的 284.1，证明
   链路束缚时争用引擎正确生效。
2. **平均排名不翻转**：三个模型下平均排名均为
   HEFT < CPOP < PSO < RANDOM。列表规划器的平均优势没有被争用推翻。
3. **争用在逐 DAG 粒度翻转第一名（R2 端点争用现象）**：cybershake-n50
   第一名 HEFT(V1) → PSO(R2/R6)；cybershake-n100 第一名 CPOP(V1) →
   PSO(R2/R6)；inspiral-n50 第一名 HEFT(V1) → CPOP(R2/R6，本轮新增，
   源自 F2 修复后 R2 数值的微小变化）。10 个 DAG 中 3 个（30%）因引入
   争用而换冠。**根因是 R2 端点争用而非 fat-tree 拓扑**——R6 与 R2 逐位
   相等，R6 列的换冠完全由 R2 继承。
4. **争用侵蚀列表规划器对 PSO 的统计显著优势**：HEFT vs PSO 配对 Wilcoxon
   V1 p=0.0371（显著）→ R2 p=0.0645、R6 p=0.0645（不显著）。HEFT vs RANDOM
   在三模型下均显著（p=0.0020）；HEFT vs CPOP 均不显著（有效 n=7；R2/R6
   下中位差为 0——端点争用把部分 DAG 上 HEFT 与 CPOP 的 makespan 拉成
   逐位相等）。
5. **敏感性：全部拓扑轴退化（含带宽轴）**：k、超收敛比、主机放置、链路
   带宽 ×10（A4）在 3 主机与 4 主机平台上对 makespan 全部恒等（配对差值
   全为零）。R7 曾报告"带宽比轴 A4 有效"——那是 ÷8 bug 把基线链路压到
   端点 1/8 后 A4（×10）恰好越过端点带宽的产物；单位修复后基线链路已
   ≥ 端点，A4 与基线同为非束缚，轴退化。含义：在静态映射 + 小规模平台 +
   链路 ≥ 端点供给下，**makespan 对 Fat-tree 参数完全不敏感**；要让拓扑
   轴产生判别力必须声明链路带宽 < 端点带宽（见 §0.8 再标定建议）。
6. **翻转依赖成本结构**：simulator 探测 IT（HEFT 论文例 + 论文成本矩阵
   fixture）中争用把平均第一名从 HEFT 翻转为 CPOP；campaign 配置（推导
   成本）下平均第一名保持 HEFT。两个装置都是实测事实，说明"排名翻转是否
   发生"对任务成本/传输时间的相对比例敏感——翻转不是无条件的。
7. **历史警示（R7 原始结论作废）**：R7 结果文档的全部 R6 数字产自三个
   bug 生效的旧物理：F1 链路 ÷8（声明 1.0 实际 0.125 MB/s）、F2 争用字节
   含本地文件、Wilcoxon 零差值参与秩和。作废的代表性数字：heft 论文例
   R6 列 5738.1/5854.1/7206.1/7262.1（新值 = R2 列 5195.1/5205.1/6281.1/
   6254.1）；cybershake-n50 PSO R6 587921.6099（新值 587924.0247 = R2）；
   "R6−R2 中位差 HEFT +103.5 s / RANDOM +441.8 s"、"A4 严格降低 makespan
   （4 主机 HEFT 中位 −285.4 s）"、"R6 vs R2 对 HEFT/CPOP/RANDOM 显著"
   ——全部不复存在。旧 R2 数字也受 F2 影响有微小漂移（如 inspiral-n30
   HEFT R2 2541516.9935 → 2541451.7694）。R7 的核心叙事"链路级争用放大
   规划器间相对惩罚差异"在本轮装置下无对应现象。**引用 R7 结论的文档
   一律以本文为准。**
8. **再标定建议（未执行，属用户决策项）**：若希望恢复 R7 原本研究的
   "拓扑轴判别力"，需把 campaign 声明链路带宽降到端点以下（例如基线
   0.125 或 0.25 MB/s、A4 = 基线 ×10），使链路成为真实瓶颈——simulator
   慢链路探针已证明该装置下模型产生可测差值。这属于实验再设计而非 bug
   修复，本轮审计未擅自执行。

弱单调性（V1 ≤ R2 ≤ R6）不是定理：全集 120 组合中本轮仅 1 处噪声级交叉
（相对偏差 3.7×10⁻⁶；R7 旧物理下为 5 处、最大 7.5×10⁻⁵——链路层退化后
交叉面缩小），已作为诊断如实输出（§4）。

R7 曾报告 A4 精确收敛回 R2（中位 −103.5 s，p=0.0059）——那是基线链路被
÷8 压到端点 1/8 后、A4（声明 ×10 = 实际 1.25 MB/s）越过端点带宽的产物。
单位修复后基线链路（1.0 MB/s）已等于端点，A4（10.0 MB/s）与基线同为
非束缚：**带宽轴失去判别力，全轴退化**。

### 3.2 4 主机结构块（120 次运行）

4 主机（4 VM）平台重跑同 6 变体（A5 = 两个同 edge 主机对
{0→0,1→0,2→2,3→2}）：**全部变体（含 A4）与基线逐位恒等**（配对差值
10(0) 全零；如 heft-paper-example HEFT 六变体全部 5186.1000、CPOP 全部
5168.1000）。R7 曾报告 4 主机下 A4 有效（HEFT 中位 −285.4 s，p=0.0020）
——同为 ÷8 旧物理产物，作废。

### 3.3 为什么全轴恒等（证据链更新）

1. **路由层**：`FatTreeTopologyTest.structuralVariantsReshapeCrossFlowSharingOnFourHosts`
   仍然锁定 4 主机下各变体确实重塑交叉流（0→2 与 1→3）的链路共享格局——
   拓扑参数生效，路由契约完好（该测试 R8 中按 ×1e6 单位契约重录断言）。
2. **动态层（R8 更换证据源）**：R7 用"A4 产生可测差值"证明争用引擎读取
   spec 的路径正确；单位修复后 A4 退化，该证据由 simulator 慢链路探针
   接替——`FatTreeContentionIntegrationTest` 在链路 0.25 MB/s（端点 1/4）
   下实测 makespan 588.1，严格大于 R2 的 284.1，且黄金值跨 JVM 复跑逐位
   稳定；对称场景（链路 = 端点 = 1.0）实测 R6 与 R2 逐位相等（284.1）。
   两个方向共同锁定：链路束缚时引擎产生正确差值，链路非束缚时精确归零。

因此恒等是动态现象而非参数失效：链路容量 ≥ 端点公平份额时，
min(端点份额, 链路份额) = 端点份额恒成立，fat-tree 层是 R2 的精确 no-op；
结构变体改变的链路共享格局在非束缚容量下不产生速率差。

**含义**：对本平台规模、这批负载与链路 ≥ 端点的供给，"改拓扑结构"与
"改带宽供给"都不是缩短 makespan 的杠杆——端点争用（R2）是唯一的网络
瓶颈层。要激活拓扑轴，见 §0.8 再标定建议。

## 4. 弱单调性诊断（V1 ≤ R2 ≤ R6）

120 组合中 1 处交叉，噪声级（相对偏差 3.7×10⁻⁶；R7 旧物理下 5 处、最大
7.5×10⁻⁵——R6 退化为 R2 后 R2→R6 段不再产生交叉，仅剩 V1→R2 段一处）：

| DAG | 规划器 | V1 | R2 | R6 | 最大相对偏差 |
| --- | --- | --- | --- | --- | --- |
| cybershake-n30 | RANDOM | 387774.9388 | 387773.5048 | 387773.5048 | 3.7e-06 |

解释：R2 端点争用改变个别传输完成时间→后续并发流格局漂移，新格局下的
公平份额可以略优于无争用格局（速率占优逐流成立，但完成时间序列可以
分叉）。诊断以 `weakMonotonicityViolations` 写入 JSON 工件；HEFT 论文例
子集上严格单调（golden IT 断言，R6 ≡ R2 使 c==b 成为常态）。

## 6. 诚实边界

- 本轮"R6 ≡ R2、全轴退化"结论条件于**链路带宽 ≥ 端点带宽**的声明装置；
  它证明的是"该装置下 fat-tree 层无附加约束"，不是"fat-tree 建模无用"
  （慢链路探针证明链路束缚时模型正确生效，§3.3）。
- 排名翻转结论限于本装置：静态映射轨道、3 主机（结构块 4 主机）同质平台、
  seed 91、推导成本（无显式成本矩阵）、10 个 DAX（3 家族；montage/sipht
  被 LOCAL 通信规划族拒绝）。探测 fixture（论文成本矩阵）显示平均排名翻转
  对成本结构敏感（§0.6）。
- PSO 换冠幅度 0.05%–0.07%、inspiral-n50 CPOP 换冠幅度 ~10⁻⁸，属"数值
  一致但微小"的翻转；其机制解释（传输热点摊开）是假设，未验证。
- R6 模型边界沿用其设计文档：流级流体模型、确定性路由、均匀链路带宽、
  单向链路键（双向流不互扰）。
- 结构轴判别力需要链路 < 端点的再标定（§0.8）或更大平台/更高传输占比
  负载才能激活；本轮如实报告"恒等"并给出证据链。
- RANDOM/PSO 结论条件于 seed 91；跨 seed 稳健性未测。
