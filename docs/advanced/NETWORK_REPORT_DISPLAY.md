# 安全离线网络报告（NF-002D2）

## 两个入口，同一验证来源

Workbench正常运行生成的报告和`Workbench report <manifest> <new-report.html>`都使用同一已验证加载器：先完成工件/哈希/账本/运行上下文校验，再从冻结的解码结果构造显示投影。原manifest与experiment索引不添加显示字段，网络数据作为HTML显示行的独立可选成员。

浏览器不读取相邻JSON文件、不运行新的仿真、不依赖服务或CDN。无效或篡改账本在独立报告目标创建前拒绝；目录中未由manifest引用的旧账本不能把OFF变成ON。

## 状态不能混淆

| 显示状态 | 含义 |
|---|---|
| OFF | 未请求网络记录；不是零流量 |
| COMPLETE · 零流 | 已开启记录，完整捕获中没有START；容量事件可能仍存在 |
| COMPLETE · 完整捕获 | 无记录丢失；通用捕获仍可能包含未完成/删失流 |
| TRUNCATED | 只有保留前缀；完整字节/FCT/资源摘要不可用，不填零 |
| 无已验证结果 | 运行失败或缺少已验证manifest；不显示前一个运行的网络表 |

选择运行时网络摘要、流表、资源表和事件表一起刷新；失败/OFF切换先清空旧数据。FCT区分有效完成与观察完成，事件使用记录的elapsed，不能用舍入后的end-start替代。

## 精确值与范围

- Long身份、接纳序号、记录序号、计数、丢弃计数及BigDecimal会计量在进入JSON.parse前转成字符串；网络时间/速率/比率也以binary64的文本表示显示。
- 不对这些精确值使用JavaScript Number、parseFloat或toLocaleString，也不拿巨大/极小精确量作图形坐标。
- 余额减少、速率积分、数值结算残差、未结余额、路径资源重复占用、局部引用和旧归组舍入差分别显示。积分区间利用率不等于全仿真利用率。
- 来源仍是V1建模受限来源，不把它标成每个文件真实选择的副本；流仍是父组/外部组，而非逐文件FCT或TCP连接。

Gson继续保护内嵌JSON的HTML字符和U+2028/U+2029，所有网络DOM使用textContent。网络标签作为数据，不能变成img、script或事件处理器。

## 显示预算与捕获预算不同

显示投影在Java序列化之前限制：

- 流摘要最多64条；资源摘要最多64条；已保留事件最多128条。
- 每处Task/路径列表最多12项；每个标签最多256个UTF-16单元再加省略号，避免截断代理对。
- 每个表保留总数、显示数、界面省略数；嵌套列表省略和标签裁剪另行统计。
- 精确数字文本不裁切。完整原始账本不会再被作为额外字段偷偷嵌入HTML。

上述界面省略不改变捕获的COMPLETE状态；实际TRUNCATED及droppedRecords单独提示。截断时完整流/资源摘要的总数为null，而不是0；事件预览仍可展示已保留前缀。

## 长数字读取与复用

MIN_VALUE平方等合法会计量可产生超过1024字符的数值token。为避免Gson流读取器把它拒绝或宽松退化成字符串，网络codec使用有界严格JSON词法读取，保持4096字符/精度/绝对scale与64层深度限制。`NetworkLedgerCodec.parseDocument`仅保证严格词法和数值类型，**不是语义证书**；完整验证仍须`decode`。网络rerun比较使用同一词法读取，等值长数字仍相等，真实微小十进制漂移仍能检出。

工件校验结果提供不可变的已解码账本与同一次验证的manifest防御性快照给显示层复用，避免再次读取路径后把A账本与已被替换的B清单混用，也避免为HTML重复解析和重算大账本。重放读取器同样使用该清单快照并确认其实际验证版本仍为v4。

## 验收方式

- 纯投影测试使用真正engine→encode→decode输入，覆盖长ID/身份重用、巨量与小于最小double的面积、代理对、恶意标签、空值和所有显示上限。
- 正常/独立报告集成测试覆盖两种流体模型、完整/截断/零流/OFF、只认manifest角色、重哈希篡改拒绝和输入不变。
- 真实Chrome验收覆盖21组报告、桌面及390px窄屏、运行状态往返切换、精确单元格与预览行数、无图片注入/脚本错误/HTTP请求/额外file读取。
- 验证器的反例副本专门破坏精确文本、把大ID转Number、隐藏面板、显示超限行或在resize时补取文件，必须失败。原报告和证据不被修改。

压力用的任意标签/极端值属于明确标记的通用流体显示夹具，`contextValidated=false`；不绕过正式bundle上下文校验，也不冒充真实Workbench网络运行。
