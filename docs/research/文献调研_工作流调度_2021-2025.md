# 启发式/元启发式/QoS 导向科学工作流调度：2021–2025 文献调研

（说明：本次调研经 OpenAlex 学术检索 API 完成；以下全部论文均为实际检索命中并附 DOI/URL；引用量为 OpenAlex 数据，仅作热度参考。）

## 1. 经典列表调度（HEFT/CPOP/PEFT 及其变体）

**改进方向**（2021–2025 年）主要集中在四类：(a) 任务优先级/关键路径估计的精细化（look-ahead、makespan 预测矩阵）；(b) 处理器选择策略的改进；(c) 受限任务复制；(d) 从 makespan 单目标扩展到成本/截止期/能耗多目标及 fog-edge 异构环境。代表论文：

- "Efficient Prioritization and Processor Selection Schemes for HEFT Algorithm: A Makespan Optimizer"（Electronics 2022，引用约 95）— 同时改优先级表与处理器选择 https://doi.org/10.3390/electronics11162557
- "A heuristic-based task scheduling algorithm for scientific workflows in heterogeneous cloud computing platform"（JKSU-CIS 2021，引用约 66） https://doi.org/10.1016/j.jksuci.2021.05.011
- "Efficient Prediction of Makespan Matrix Workflow Scheduling Algorithm for Heterogeneous Cloud Environments"（Journal of Grid Computing 2023） https://doi.org/10.1007/s10723-023-09711-9
- "Limited Duplication-Based List Scheduling Algorithm for Heterogeneous Computing System"（Micromachines 2022） https://doi.org/10.3390/mi13071067
- "Bi-objective scheduling algorithm for scientific workflows … makespan and monetary cost"（Complex & Intelligent Systems 2021） https://doi.org/10.1007/s40747-021-00528-1

**增量还是创新？** 大体判断：约八成属于"增量灌水"——新组合的排序函数/选择规则在固定基准上报告小幅 makespan 提升，缺少统计检验与新问题设置。但确有实质创新的子集：把 look-ahead 预测做成有原则的近似（如上述 makespan-matrix 工作）、以及把列表调度扩展到真实约束组合（多核资源、能耗、成本）。学界态度正在转变：两篇 2024 年系统综述明确把"评估方法学缺陷、缺乏公平复现基准"列为该领域的主要 gap：
- "AI-based & heuristic workflow scheduling in cloud and fog computing: a systematic review"（Cluster Computing 2024） https://doi.org/10.1007/s10586-024-04442-2
- "Trends, Approaches, and Gaps in Scientific Workflow Scheduling: A Systematic Review"（IEEE Access 2024） https://doi.org/10.1109/access.2024.3509218

## 2. 元启发式（GA/PSO/ACO/蜂群/鲸鱼等）：饱和与可复现性批评

**饱和判断**：作为"发明新生物隐喻算法 + 在工作流调度上跑一遍"的范式，已经饱和且被公开批评。综述显示 PSO 类在云调度中占比极高（"A survey on PSO based meta-heuristic scheduling mechanism in cloud computing environment"，JKSU-CIS 2021 https://doi.org/10.1016/j.jksuci.2021.01.003）。但 2023–2025 仍有有影响力的工作——共性是**混合化、面向具体约束（deadline+budget）、或转向 DRL**，而非新隐喻：
- DB-ACO: A Deadline-Budget Constrained Ant Colony Optimization（IEEE T-ASE 2023，引用 56） https://doi.org/10.1109/tase.2023.3247973
- Multi-Objective Grey Wolf Optimizer for Task Scheduling in Cloud-Fog（IEEE Access 2023，引用约 160） https://doi.org/10.1109/access.2023.3241240
- NSGA-II with semi-greedy initialization, fog-cloud（Applied Soft Computing 2023） https://doi.org/10.1016/j.asoc.2023.111142

**可复现性/方法学批评线索（这是近年最健康的趋势）**：
- Sörensen, "Metaheuristics—the metaphor exposed"（ITORS 2013，引用 1039） https://doi.org/10.1111/itor.12001
- "Metaphor-based metaheuristics, a call for action: the elephant in the room"（Swarm Intelligence 2021，引用 188） https://doi.org/10.1007/s11721-021-00202-9
- "Mitigating Metaphors: A Comprehensible Guide to Recent Nature-Inspired Algorithms"（SN Computer Science 2019） https://doi.org/10.1007/s42979-019-0050-8
- Blum & Ochoa 等, "A prescription of methodological guidelines for comparing bio-inspired optimization algorithms"（Swarm and Evolutionary Computation 2021，引用 185） https://doi.org/10.1016/j.swevo.2021.100973
- "Large-Scale Benchmarking of Metaphor-Based Optimization Heuristics"（GECCO 2024） https://doi.org/10.1145/3638529.3654122
- Rao, "Rao algorithms: Three metaphor-less simple algorithms"（IJIEC 2020） https://doi.org/10.5267/j.ijiec.2019.6.002

结论：审稿层面对"新动物启发算法"的容忍度持续下降；带 Wilcoxon 检验、效应量、公开代码的论文才容易通过。

## 3. Deadline/预算约束与公平性（multi-tenant）

**Deadline/预算**是列表调度与元启发式最活跃的落点：
- ET2FA: A Hybrid Heuristic Algorithm for Deadline-constrained Workflow Scheduling（IEEE TSC 2022，引用 51） https://doi.org/10.1109/tsc.2022.3196620
- "Cost-Efficient Workflow Scheduling Algorithm for Applications With Deadline Constraint on Heterogeneous Clouds"（IEEE TPDS 2021，引用 96） https://doi.org/10.1109/tpds.2021.3134247
- "A Fully Hybrid Algorithm for Deadline Constrained Workflow Scheduling in Clouds"（IEEE TCC 2023） https://doi.org/10.1109/tcc.2023.3269144
- "A Budget-Constrained Workflow Scheduling Approach With Priority Adjustment and Critical Task Optimizing"（IEEE T-ASE 2024） https://doi.org/10.1109/tase.2024.3456762
- "Energy-efficient workflow scheduling with budget-deadline constraints for cloud"（Computing 2022） https://doi.org/10.1007/s00607-021-01030-9

**公平性**：直接针对"多租户 DAG 工作流公平调度"的工作明显稀缺，现有工作多为相邻形态：
- SG-PBFS: Shortest Gap-Priority Based Fair Scheduling for job scheduling in cloud（FGCS 2023，引用 52，但面向扁平 job） https://doi.org/10.1016/j.future.2023.09.005
- "Proportional Fairness-Aware Task Scheduling in Space-Air-Ground Integrated Networks"（IEEE TSC 2024） https://doi.org/10.1109/tsc.2024.3478730
- ASTRAEA: A Fair Deep Learning Scheduler for Multi-Tenant GPU Clusters（IEEE TPDS 2021） https://doi.org/10.1109/tpds.2021.3136245
- "One for All: Unified Workload Prediction for Dynamic Multi-tenant Edge Cloud Platforms"（KDD 2023） https://doi.org/10.1145/3580305.3599453
→ **空白点**：把 proportional/max-min 公平语义扩展到并发 DAG 工作流的 makespan/延迟权衡，几乎没有成熟工作。

## 4. 多工作流并发/动态到达（与平台的错峰到达功能直接相关）

- 经典基线是 ensemble provisioning："Algorithms for cost- and deadline-constrained provisioning for scientific workflow ensembles in IaaS clouds"（FGCS 2016，引用 234） https://doi.org/10.1016/j.future.2015.01.004 及 SC'12 版 https://doi.org/10.1109/sc.2012.38
- "Adaptive Cloud Bundle Provisioning and Multi-Workflow Scheduling via Coalition Reinforcement Learning"（IEEE TC 2022） https://doi.org/10.1109/tc.2022.3191733
- "A collaborative multi-objective meta-heuristic for deadline-constrained multi-workflows scheduling in cloud"（EAAI 2024） https://doi.org/10.1016/j.engappai.2024.109907
- "Levelized Multiple Workflow Allocation Strategy Under Precedence Constraints With Task Merging in IaaS"（IEEE Access 2022） https://doi.org/10.1109/access.2022.3202651
- "An Adaptive Budget and Deadline-aware Algorithm for Scheduling Workflows Ensemble in IaaS Clouds"（ICCKE 2023） https://doi.org/10.1109/iccke60553.2023.10326305
- "Multi Objective Prioritized Workflow Scheduling Using Deep Reinforcement Based Learning"（IEEE Access 2024） https://doi.org/10.1109/access.2024.3350741
- 在线/动态侧："Real-time and dynamic fault-tolerant scheduling for scientific workflows in clouds"（Information Sciences 2021） https://doi.org/10.1016/j.ins.2021.03.003；"Learning to Optimize Workflow Scheduling for an Edge–Cloud Computing Environment"（IEEE TCC 2024） https://doi.org/10.1109/tcc.2024.3408006

**观察**：这一方向文献量明显偏少，且多数 multi-workflow 工作把多个 DAG 当成**静态批处理**一次性调度；按 Poisson/错峰到达的**在线**评测、到达间隔对列表调度优先级表的影响，基本没有系统性研究。这正是你们平台新增功能的独特卡位。

## 5. 对平台（CloudSim 3/WorkflowSim + HEFT/CPOP/PEFT 复现 + PSO + 8 在线调度器 + 错峰到达 + Wilcoxon）的启示：未做透的研究问题

1. **错峰到达下的在线列表调度评测**（最稀缺）：HEFT 类算法全部为静态设计，到达间隔、负载强度如何改变其相对排名？用你们的 8 个在线调度器 + 配对 Wilcoxon 给出第一份"在线版 HEFT/CPOP/PEFT 复现基准"，可投 TPDS/TSC/CCPE 级别。
2. **公平性 × 多工作流**：SG-PBFS 只做扁平 job；把 proportional fair/max-min 语义引入并发 DAG（定义公平指标，如 per-user slowdown 的 Jain index）几乎是空白，且平台的多工作流错峰功能恰好是实验设施。
3. **可复现基准论文本身**：2024 两篇系统综述都点名"缺少公平可复现的评测基准"；你们的"论文级复现 + 显著性检验"组合正是社区在 Blum-Ochoa 指南（https://doi.org/10.1016/j.swevo.2021.100973）与 GECCO 2024 基准（https://doi.org/10.1145/3638529.3654122）中呼吁的东西——可做"reproducible benchmark of workflow scheduling heuristics"。
4. **Deadline/预算约束的在线化**：文献里的 deadline 算法几乎全是离线的；在线版本（任务到达时才决策、可拒绝或排队）报告 deadline-violation rate–cost 权衡曲线的很少。
5. **PSO 的在线/增量形态**：静态 PSO 已饱和，但"到达驱动的增量重优化 PSO"几乎没有工作；可作为元启发式方向唯一仍有新意空间的切入点。
6. **平台自身即成果**：WorkflowSim 原始论文（https://doi.org/10.1109/escience.2012.6404430，引用 492）后社区缺乏维护中的仿真基准，你们的扩展（多工作流错峰到达、显著性检验管线）值得单独发一篇工具/基准论文。

**总体判断**：纯算法改良（又一个 HEFT 变体/新动物隐喻）的边际价值已接近零；该领域的增量空间集中在 **在线/多工作流/公平性/可复现评测** 四个交叉点，而平台的现有能力恰好覆盖这四者的实验基础设施。
